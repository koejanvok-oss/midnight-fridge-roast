# Midnight Fridge Roast

A [make.fun](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) entry: one line roasting a smart fridge that refuses to open after midnight.

`main.py` writes the roast to `/output/entry.txt`:

> The fridge installed a curfew, and I, the adult who bought it, am the one grounded.

Run it with:

```sh
python3 main.py
```
